## Project Overview

CleverKeys is a privacy-first gesture typing system for local-only modern keyboards - a high-performance Gboard alternative that never sends data off-device. 

Project uses uv and training is done with an RTX 4090M with 16GB VRAM. CPU is i9-14900hx.
